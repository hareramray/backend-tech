The collection contains separate Markdown tutorials for backend foundations, databases, security, background processing, APIs, testing, operations, architecture, and Django. It includes a complete local Task Service walkthrough, exercises, failure drills, a glossary, and a production-readiness checklist.

For a guided sequence, open the [learning path](backend-tutorials/LEARNING-PATH.md). For hands-on setup, open the [Django/PostgreSQL capstone](backend-tutorials/09-capstone/01-task-service.md).

For system design, open the [15-chapter architecture study map](backend-tutorials/08-architecture/README.md) and [six worked designs](backend-tutorials/11-system-design-case-studies/README.md): URL shortening, chat, feeds, video, reservations, and notifications.
